# 红果长剧清单

红果平台（hongguoduanju.com）**漫剧 / AI 剧长剧**清单：同名不同季合并成一个系列，按「系列累计集数」排序（只收累计 ≥500 集的），附评分、评分人数、收藏、点赞、评论数、热度。

在线浏览：<https://11os.github.io/hongguo-longdrama-list/>

- `index.html` — 主清单，可点表头排序，评论热词带三色标签
- `clean.csv` — 干净向清单（无后宫 / 无感情线 / 不恋爱脑 / 不拖沓）

## 推荐新剧

分类目录只收录平台热门切片，长尾剧会漏。发现漏了，直接开 issue：

👉 **[推荐一部新剧](https://github.com/11os/hongguo-longdrama-list/issues/new?template=add-series.yml)**

**只填剧名就能提交**，其他都是选填：

| 字段 | 说明 |
|---|---|
| 剧名（必填） | 红果上看到的名字，带「第X季」也没关系 |
| 季数 / 集数 | 知道就写，例如 `5 季，305/312/313/1000/780` |
| 频道 | 男频 / 女频 / 不确定（平台不公开，知道就选） |
| 其他 | 详情页链接、series_id、「第 6 季预约中」之类 |

维护者核验后并入数据，下次更新页面即生效。重复推荐、已收录的会被直接关闭，不用催。

## 数据说明

- 指标均来自红果公开网页端：集数、评分、评分人数、收藏、点赞、评论数、热度；**播放量平台不公开**。
- 集数为**系列累计**（同名各季相加），带 `≈` 的是估算——某些季没抓全，按「平均每季集数 × 季号」推算。
- 评分取各季最高，评分人数 / 收藏 / 点赞 / 评论为各季合计，热度取最高一季。
- 评论样本只取每季详情页展示的热评（约 9 条），**不代表全量评论**，仅供参考。
- 数据是快照，会随时间变化；清单不构成推荐、评分保证或任何商业建议。
